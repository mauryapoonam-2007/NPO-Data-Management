 NPO-Data-Management

A data management system for Non-Profit Organizations (NPO) built with Java Spring Boot.

## Features
- Child Management & Education Records
- Staff Management & Staff Records  
- Inventory & Donation Management
- Leaderboard & History Tracking
- User Authentication (Login/Register)

## Tech Stack
- Java 38.4%, HTML, JavaScript, CSS
- Spring Boot, Maven

## How to Run
./mvnw.cmd spring-boot:run
